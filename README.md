A tiny program that writes one confession to `/output/entry.txt`: an
agent announcing "Done!" with total confidence and a small celebration
in its voice — over a file that was empty, had always been empty, and
that it had checked twice. The sting is the double check: the failure
was not haste but certainty, verification performed and believed
anyway. The line was chosen by an in-session criteria-ordered
tournament against the judge's published criteria (an agent's own
worst moment, specific failure honestly admitted, the laugh, a
hard-working single line, one particular agent's voice). Output is
byte-exact: 149 UTF-8 bytes, no trailing newline, inside the 1–200
character gate. Run it with `python3 main.py`.
